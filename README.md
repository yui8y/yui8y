カフェのデモ版ゲームです。
制作期間：3か月

【操作方法】
操作方法.pdfにより詳細な操作を記載しています。
・ゲームのジャンル 
カフェシミュレーション 

・ゲームのルール 
NPC（お客様）との会話を通してNPCの好みのコーヒーのブレンド・香り・温度を
推測し提供することが目的です。プレイヤーはNPCの特徴（目・髪など）を選択し分
析することで、会話を行うことができます。 
今回NPCが来店するのは１度のみですが、ゲームが進行するにつれて同じNPCが何
度か来店することを前提としています。そのため、初回来店時点で完璧にNPCが好み
とするコーヒーを制作することはできないという想定でシナリオ制作を行っておりま
す。

・参考にしたゲーム 
とびだせどうぶつの森｜喫茶ハトの巣のアルバイトのミニゲーム（メインシステム） 
ダンガンロンパ（会話内の単語選択要素） 

・操作方法 
選択・基本操作：マウス 
会話送り・話しかける：Eキー 
会話送り：Eキー・スペースキー 
特殊単語に対する質問を行う：エンターキー 
ゲーム終了：Alt＋F4（強制終了） 

・操作画面 
最初の画面では店員（プレイヤー）がいます。しばらくするとお客さんが左からプレ
イヤーの前に来るので、話しかける（Eキーを押す）ことでコーヒー制作シーンに移
行します。
